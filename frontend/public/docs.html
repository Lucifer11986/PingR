Alles was du wissen musst um Bots für Nokki zu bauen

⚠️ Beta-Status

Die Developer Platform befindet sich in der Beta. Eine öffentliche, versionierte REST-API und offizielle SDKs sind noch nicht freigegeben. Verwende nur die hier dokumentierten Portal- und Bot-Funktionen.

🚀 Quick Start

In wenigen Schritten zum ersten Bot:

1. Developer-Account unter /dev-register erstellen
2. API-Key einmalig sicher speichern
3. Bot im Dashboard erstellen
4. Installationslink an einen Gruppenadmin senden
5. Webhook im Portal registrieren und testen

📚 Core Konzepte

Bots: Automatisierte Accounts die mit Nutzern interagieren können

Channels: Öffentliche Broadcast-Kanäle (wie Telegram Channels)

Messages: Text, Bilder, Files, Voice - mit Rich Formatting

Webhooks: Echtzeit-Benachrichtigungen für Events

Permissions: Granulare Berechtigungen die User authorisieren

🔑 Authentication

Alle API-Requests benötigen einen Bearer Token im Authorization Header:

Authorization: Bearer sk_live_abc123...

API Keys im Dashboard erstellen: Dashboard →

📡 Aktuell verfügbare Bereiche

/api/dev/bots – eigene Bots verwalten

/api/bot-webhooks – sichere Webhooks verwalten

/api/bot-scheduler – geplante Bot-Nachrichten

/api/bot-analytics – gespeicherte Bot-Metriken

Die vollständigen Methoden und Berechtigungen findest du im eingeloggten Wiki.

🔔 Webhooks

Registriere im Developer-Portal eine öffentliche HTTPS-URL. Lokale und private Netzwerkziele werden aus Sicherheitsgründen abgewiesen.

Events: message.create, message.delete, message.edit, member.join, member.leave, command.execute

Jede Auslieferung enthält eine HMAC-SHA256-Signatur. Das Secret wird nur beim Erzeugen vollständig angezeigt.

📦 SDKs

Offizielle SDKs sind noch nicht veröffentlicht. Installiere derzeit keine Pakete, die sich ohne Nachweis als offizielles Nokki-SDK ausgeben.
