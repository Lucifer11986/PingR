In wenigen Schritten startklar

Wähle dein Betriebssystem für die passende Installationsanleitung.

Installation unter Windows

  1. Lade den Setup-Assistenten oder die portable ZIP-Datei herunter.
  2. Öffne die Datei. Bei einer SmartScreen-Warnung prüfe den Herausgeber und wähle bei Vertrauen Weitere Informationen → Trotzdem ausführen.
  3. Melde dich mit deinem Nokki-Konto an.

Installation unter macOS

  1. Öffne die DMG-Datei und ziehe Nokki in den Ordner Programme.
  2. Falls macOS die App blockiert, öffne Systemeinstellungen → Datenschutz & Sicherheit und erlaube den Start nur, wenn du der Quelle vertraust.
  3. Starte Nokki aus dem Programme-Ordner.

Installation unter Linux

  1. Für Debian/Ubuntu: lade das DEB-Paket und installiere es mit deinem Paketmanager.
  2. Für AppImage: mache die Datei ausführbar und starte sie.
chmod +x Nokki-1.0.0-linux-x86_64.AppImage
./Nokki-1.0.0-linux-x86_64.AppImage

Fragen zum Download

Warum zeigt mein System eine Sicherheitswarnung?
Windows SmartScreen und macOS Gatekeeper können bei neuen oder noch nicht signierten Apps warnen. Lade Nokki ausschließlich von dieser Seite und prüfe die Quelle, bevor du eine Warnung übergehst.
Was ist der Unterschied zwischen Setup und portabler Version?
Das Setup installiert Nokki normal im System. Die portable Windows-Version wird nur entpackt und benötigt keine Installation – praktisch für USB-Sticks oder Geräte ohne Installationsrechte.
Ein Download ist noch nicht verfügbar – was nun?
Die Schaltfläche wird automatisch aktiviert, sobald das passende Paket auf dem Server liegt. Bis dahin kannst du Nokki ohne Einschränkung im Browser verwenden.
Wie prüfe ich eine heruntergeladene Datei?
Unter Linux oder macOS kannst du mit sha256sum DATEI beziehungsweise shasum -a 256 DATEI einen Prüfschlüssel erzeugen. Unter Windows verwendest du Get-FileHash DATEI in PowerShell.
