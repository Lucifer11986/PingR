API Reference

Vollständige Referenz aller API Endpoints

Messages

POST/v1/bot/message/send

Sende eine Nachricht an einen User oder Channel

channel_id string required - Channel ID
text string required - Nachrichtentext (max 4000 Zeichen)
markdown boolean optional - Markdown aktivieren
GET/v1/bot/messages

Hole letzte Nachrichten aus einem Channel

channel_id string required
limit number optional - Max 100
DELETE/v1/bot/message/:id

Lösche eine Bot-Nachricht

Channels

POST/v1/bot/channel/join

Tritt einem öffentlichen Channel bei

channel_id string required
GET/v1/bot/channel/:id

Hole Channel-Informationen

Users

GET/v1/bot/user/:id

Hole User-Profil Informationen
